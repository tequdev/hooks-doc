These examples show complete Hook workflows that build on the API reference.

## Worked examples

- [Payment filter](payment-filter) — inspect an incoming payment and decide whether to accept it.
- [State counter](state-counter) — read, increment, and write hook state.
- [Emitted transaction](emitted-transaction) — reserve, prepare, and emit a transaction.
