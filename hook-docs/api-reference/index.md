# API Reference

This section collects the detailed Hook API docs by function group.

## Groups

- [Control](control/) — core flow control, hook identity, parameters, and rollback.
- [Transaction](transaction/) — read information from the originating transaction.
- [State](state/) — read and write persistent hook state.
- [Slot](slot/) — work with slot handles and slot contents.
- [Ledger](ledger/) — inspect ledger values and keylets.
- [Emit](emit/) — reserve, prepare, and emit transactions.
- [Float](float/) — XFL arithmetic and conversions.
- [Utility](utility/) — address conversion, keylet derivation, verification helpers.
- [STO](sto/) — serialized-object inspection and editing.
- [Trace](trace/) — debug tracing helpers.
